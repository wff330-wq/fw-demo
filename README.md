# 廚餘管理平台 — H5 示範版

單一 HTML 檔，無需安裝、無需網絡、無需後端。用手機瀏覽器開同樣可以（自動 responsive）。

**示範數據**：畫面所有數字皆為模擬資料，不代表任何真實機構。

---

## 入面有咩

### 供應商視角
- 自選任何日期區間（本月／上月／近 7 日／近 30 日／自訂）
- 本期總量、日均量、收集次數、待簽收紀錄
- 每日收集量圖表，按廚餘／廢食油／其他有機廢物分佈
- 逐筆收集紀錄：日期、時間、收集點、類別、重量、車輛、處理設施、簽收狀態、紀錄編號
- 匯出 CSV（Excel 可直接開，含 BOM）
- 列印 / 儲存 PDF
- 繁中／英文切換

### 監察實體視角
- 全體供應商總覽（12 間）
- 各供應商本期收集量排名圖
- 本期 vs 上期比較、變化百分比
- 最後收集日期 + 超過 7 日無紀錄警示
- 簽收率、待簽收統計
- 匯出全體紀錄 CSV

|---|---|
| 廚餘供應商 | 登入頁按「登入」（手機號 + 驗證碼已預填） |

## 邊啲係真、邊啲係假

| 項目 | 狀態 |
|---|---|
| 介面、互動、圖表、匯出、列印、雙語 | 真實可運作 |
| 所有數據（12 間供應商、約 2,000 筆紀錄、200 日曆史） | 模擬，固定種子 |
| 登入 | 假登入，冇驗證、冇 session、冇後端 |
| 數據來源 | 未接駁任何過磅系統／後台 API |

## 正式版要加咩

1. 真實認證 — SMS OTP 或多角色權限
2. 數據接入 — 對接現有過磅紀錄／收集行程後台，或提供匯入介面
3. 數據隔離 — 供應商只能見到自己嘅紀錄（伺服器端強制）
4. 審計紀錄 — 誰在何時查閱／匯出咩
5. 後台管理 — 供應商開戶、收集點維護、異常申報
6. 私有化部署 — 內網伺服器、備份、HTTPS、日誌
7. UAT + 文件 — 使用手冊、驗收報告
